# アプリケーション検証

以下を順番に実行してください。

## 1. TypeScript 型チェック

```bash
pnpm tsc --noEmit
```

## 2. ESLint

```bash
pnpm lint
```

## 3. ビルド

```bash
pnpm build
```

## エラー対応

エラーが発生した場合：

1. エラーメッセージを分析
2. 該当ファイルを特定・修正
3. 再度検証を実行

**すべてのチェックがパスするまで自動的に修正を繰り返してください。**
