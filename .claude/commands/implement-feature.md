## Feature: $ARGUMENTS

### Step 1: 設計（コードを書かない）
1. CLAUDE.md でプロジェクトコンテキストを確認
2. 影響するファイルとコンポーネントを特定
3. インターフェースを設計（型、関数シグネチャ）
4. エッジケースとエラーハンドリングを考慮
5. 設計をレビュー用に提示

### Step 2: 実装（設計承認後）
1. 型定義を作成/更新
2. Repository を実装（DB操作）
3. Server Actions を実装（ユースケース）
4. UIコンポーネントを作成
5. pnpm tsc --noEmit で型チェック
6. pnpm lint でリント

### Step 3: 検証
1. ブラウザで手動テスト
2. コンソールエラーの確認
3. RLSポリシーの動作確認
